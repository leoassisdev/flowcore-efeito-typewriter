## Como instalar

1. **Instale as dependências**

   ```bash
   npm install gsap
   ```

2. **Crie src/components/TextType.tsx** Copie o conteúdo de `src/TextType.tsx` e `src/TextType.css` deste repositório. Esse efeito também tem TextType.css: crie ao lado.
3. **Use na página**

   ```tsx
   <TextType text={['Frase 1','Frase 2']} typingSpeed={75} />
   ```
